# TrackerTalk 0.8.8

Atualizar deixou de exigir que você interrompa o que está fazendo.

## A conversa em andamento não atrapalha mais a instalação

Quando o TrackerTalk está acompanhando uma conversa, o programa fica em
execução — e o Windows não permite substituir um programa em uso. A versão
anterior explicava isso e pedia que a conversa fosse encerrada antes de
continuar. Funcionava, mas custava caro: interromper o trabalho só para
instalar uma atualização.

O Windows recusa apagar e sobrescrever um programa em uso, mas aceita
movê-lo de lugar, e o processo continua rodando normalmente a partir do
arquivo movido. O instalador passa a usar esse caminho: tira o programa
antigo da frente e coloca o novo no lugar.

Na prática:

- **você não precisa fechar nada** — a instalação simplesmente prossegue;
- a conversa aberta continua até você terminá-la, sem ser encerrada e sem
  perder o rastreamento;
- conversas iniciadas depois já usam a versão nova;
- o arquivo antigo é removido sozinho na atualização seguinte ou na
  desinstalação.

É a mesma técnica que os navegadores usam para se atualizar sem fechar as
abas abertas.

O aviso pedindo para encerrar a conversa continua existindo, agora como
último recurso: se nem mover o arquivo for possível — um antivírus
segurando o programa naquele instante, por exemplo —, a mensagem aparece e
oferece nova tentativa.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao das versões anteriores;
- dados e rastreios existentes são preservados;
- tudo o que veio nas versões 0.8.4 a 0.8.7 continua incluído.

## Atualizando

Execute o instalador por cima da instalação atual. Se o ícone do
TrackerTalk estiver na área de notificação, escolha **Sair** antes de
abrir a versão nova; conversas em andamento podem continuar abertas.

Uma observação para quem vem de uma versão anterior a esta: quem instala é
o programa da versão nova, mas o obstáculo acontece antes dele assumir.
Se houver uma conversa em andamento agora, você ainda verá o pedido para
encerrá-la desta vez. A partir desta versão, não mais.
