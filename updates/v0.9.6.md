# TrackerTalk 0.9.6

Projetos passam a ser criados por você, no lugar de serem deduzidos da
pasta em que a conversa aconteceu.

## Você agrupa as conversas do seu jeito

O filtro por projeto, que estreou há poucas versões, tentava adivinhar o
projeto pelo diretório de trabalho da conversa. Isso não funciona para
quem mantém uma cópia de trabalho por branch: a mesma pasta aparece
dezenas de vezes, e a lista só cresce a cada nova branch. O problema não
era o nome mostrado, era a premissa de que o programa poderia adivinhar
o agrupamento certo.

Agora um projeto é uma decisão sua:

- **crie** um projeto com o nome que fizer sentido, sem limite de
  quantos;
- **mova** uma conversa pelo menu de ações, ou várias de uma vez
  selecionando e usando **Mover para projeto**;
- **renomeie** ou **apague** um projeto no mesmo lugar;
- cada conversa mostra uma etiqueta com o projeto a que pertence, e o
  filtro traz a contagem de cada um.

O filtro lista apenas os projetos que você criou, mais **Sem projeto**
para as conversas ainda não agrupadas. A busca também encontra pelo nome
do projeto.

## Nada é apagado ao desagrupar

Tirar uma conversa de um projeto não apaga a conversa. Apagar um projeto
também não: as conversas apenas deixam de estar agrupadas e continuam na
lista, marcadas como sem projeto. A mensagem exibida ao apagar diz
quantas conversas foram liberadas, justamente para não restar dúvida.

## A pasta continua visível

O diretório em que a conversa aconteceu continua no cartão, em
**Mostrar detalhes**, mas agora aparece como **Pasta**. Projeto passou a
significar outra coisa, e a mesma palavra não pode ter dois sentidos na
mesma tela.

## Sobre os rastreios que você já tem

Eles começam sem projeto, e é de propósito. Distribuir automaticamente
com base no caminho seria repetir exatamente o problema que esta versão
corrige. Você agrupa o que quiser, quando quiser.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao das versões anteriores;
- dados, rastreios e imagens existentes são preservados;
- os projetos ficam em um arquivo próprio na pasta de dados local.

## Atualizando

Execute o instalador por cima da instalação atual. Conversas em
andamento podem continuar abertas.
