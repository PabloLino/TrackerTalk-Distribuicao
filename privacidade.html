Aplicativo TrackerTalk

O TrackerTalk foi projetado para preservar e consultar conversas na máquina do próprio usuário. O conteúdo das conversas, imagens copiadas, títulos, caminhos de projeto e identificadores de rastreio não são enviados para um servidor do produto.

Verificação de atualizações

Quando o recurso estiver presente no aplicativo, ele consultará um manifesto público por HTTPS para descobrir o número da versão atual. Essa solicitação não incluirá conversas, projetos, credenciais ou identificadores de rastreio.

Como em qualquer acesso HTTP, o provedor de hospedagem pode receber dados técnicos necessários à conexão, como endereço IP, data, horário, agente de usuário e URL solicitada, conforme as políticas do próprio provedor.

Site de distribuição

Este site é estático e não utiliza conta de usuário, formulário, cookies próprios de publicidade ou ferramentas próprias de análise. Ele é hospedado pelo GitHub Pages e os instaladores são fornecidos pelo GitHub Releases.

Arquivos baixados

Os downloads podem ser registrados pelo provedor de hospedagem. O site publica tamanho, número da versão e SHA-256 para permitir a conferência do arquivo recebido.

Dados removidos na desinstalação

O desinstalador remove o aplicativo, atalhos, inicialização automática e entrada de PATH. A exclusão das cópias locais em %LOCALAPPDATA%\TrackerTalk exige uma escolha separada e explícita.

Alterações desta página

Mudanças relevantes serão registradas com uma nova data de atualização. O histórico deste documento permanece disponível no repositório público de distribuição.
