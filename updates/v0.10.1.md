# TrackerTalk 0.10.1

Uma conversa do Claude Code que passa para outro arquivo deixa de pedir
rastreio de novo e continua sendo copiada no mesmo rastreio.

## O que acontecia

O Claude Code às vezes passa uma conversa em andamento para um arquivo novo.
No arquivo antigo fica um registro apontando o novo, e o novo começa com uma
cópia de tudo o que já tinha sido dito.

O TrackerTalk não conhecia esse registro, e isso tinha três efeitos:

- a bandeja via o arquivo novo como outra conversa e perguntava de novo se
  devia rastreá-la;
- o rastreio original continuava acompanhando o arquivo antigo, que não
  mudava mais, então as mensagens seguintes não eram copiadas, embora a
  conversa aparecesse como rastreada;
- aceitar o segundo aviso criava um rastreio duplicado. A partir da 0.10.0,
  esse duplicado era encerrado poucos segundos depois, porque o terminal
  ficava associado ao arquivo antigo, e a cópia parava de vez.

## O que muda

O rastreio passa a acompanhar todos os arquivos da conversa: o original e
cada um para onde ela for passada. Cada arquivo tem a sua própria cópia, e o
segundo aviso não aparece mais.

Na leitura, os arquivos são juntados na ordem em que as mensagens
aconteceram. O que o arquivo novo repete do antigo aparece uma vez só.

A retomada abre a conversa pelo arquivo que teve atividade por último. Em
geral é o novo, mas a conversa pode voltar para o antigo, e então é por ele.

Fechar o terminal continua encerrando o rastreio, como sempre. A diferença é
que um terminal associado ao arquivo antigo não faz mais a conversa parecer
encerrada enquanto ela segue no novo.

Vale para as conversas detectadas pela bandeja, para as abertas pelo
TrackerTalk e para o `trackertalk attach`.

## Conversas afetadas antes desta versão

Na primeira vez que a bandeja abre depois de atualizar, o TrackerTalk procura
nas cópias que já tem as conversas que passaram para outro arquivo e copia a
continuação para o rastreio original. Isso funciona enquanto o arquivo da
conversa ainda existir no Claude Code.

Se você aceitou o segundo aviso, o rastreio duplicado continua na lista:
excluir rastreio é decisão sua. Excluí-lo não interrompe a cópia do rastreio
original, e um duplicado excluído em versão anterior também deixa de impedir
essa cópia.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao das versões anteriores;
- dados, rastreios, projetos e imagens existentes são preservados; os
  arquivos do Claude Code são apenas lidos;
- verificada a atualização a partir da 0.10.0 com o programa aberto.

## Atualizando

Execute o instalador por cima da instalação atual. Conversas em
andamento podem continuar abertas.

O instalador ainda não possui assinatura Authenticode. O Windows Defender
SmartScreen pode apresentar um aviso antes da execução. A página de
distribuição explica o que fazer e como verificar o arquivo.
