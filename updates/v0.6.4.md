# TrackerTalk 0.6.4

Primeira versão publicada no canal público de distribuição.

## Principais recursos

- rastreio local de sessões do Codex CLI, Claude Code, Gemini CLI e GitHub Copilot CLI;
- detecção de terminais de IA abertos e ainda não rastreados;
- cópia contínua de mensagens e imagens sem interferir no terminal original;
- busca no conteúdo preservado;
- visualização formatada da conversa completa;
- retomada pelo ID nativo do provedor;
- continuidade de contexto entre diferentes LLMs;
- painel escuro ou claro;
- mascote-guia Trakino;
- inicialização com o Windows marcada por padrão e desativável;
- desinstalação segura com preservação dos dados por padrão.
