# TrackerTalk 0.9.14

Retomar uma conversa do Codex com **Executar como administrador** volta a
funcionar.

## O que mudou no Codex

A partir da versão 0.158.0, o Codex passou a usar um servidor em segundo
plano, compartilhado entre todos os terminais em que ele roda. Esse servidor
se recusa a nascer em um terminal de administrador, e a recusa é de
propósito: se ele subisse elevado, qualquer terminal comum que conversasse
com ele herdaria o privilégio.

Na prática, marcar a opção de administrador no diálogo **Abrir retomada no
terminal** abria a janela elevada e o Codex encerrava na hora com:

```text
Error: start the Windows daemon from a non-elevated terminal; shared clients
must not inherit administrator privileges
```

Sem a opção marcada, tudo funcionava. Nada tinha mudado no TrackerTalk; foi o
Codex que passou a exigir outro jeito de ser aberto como administrador.

## O que o TrackerTalk faz agora

Quando o Codex vai rodar em um terminal elevado, o TrackerTalk acrescenta a
opção `--no-daemon`, que o próprio Codex indica para esse caso. Com ela, o
Codex trabalha dentro daquele terminal, sem passar pelo servidor
compartilhado. É exatamente o que quem marca a opção de administrador quer:
que as ferramentas rodem elevadas ali mesmo.

Uma linha no terminal avisa quando isso acontece, para a mudança não ser
invisível.

## Só quando é necessário e seguro

A opção só é acrescentada quando tudo isto vale ao mesmo tempo: o provedor é
o Codex, o terminal está como administrador, e o Codex instalado conhece a
opção. Versões mais antigas do Codex não a conhecem e recusariam a retomada
inteira se a recebessem, então o TrackerTalk pergunta ao próprio Codex antes
de usá-la, em vez de supor pela versão.

Em um terminal comum, nada muda: o Codex continua usando o servidor dele como
sempre. Os demais provedores não são afetados.

## O rastreio continua igual

Sem o servidor compartilhado, o Codex continua gravando a conversa no mesmo
arquivo de sessão de sempre, que é de onde o TrackerTalk lê. A conversa
retomada como administrador é acompanhada normalmente, e vale o mesmo para
**Continuar com outro LLM** e para uma sessão nova aberta pelo TrackerTalk.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao das versões anteriores;
- dados, rastreios, projetos e imagens existentes são preservados;
- verificado com o Codex 0.158.0 e 0.159.2.

## Atualizando

Execute o instalador por cima da instalação atual. Conversas em
andamento podem continuar abertas.
