# TrackerTalk 0.10.3

Com vários terminais abertos, o painel agora mostra em qual deles está a
conversa que você está lendo.

## Mostrar terminal

Na página de uma conversa, o botão **Mostrar terminal** traz para a frente a
janela do terminal em que ela está rodando. Na lista de conversas, o botão ◎
faz o mesmo. O botão só fica habilitado quando a conversa está aberta em um
terminal.

Depois do clique, um aviso diz o que foi feito:

- **Windows Terminal:** a janela vem para a frente, e o aviso diz o nome da
  aba em que a conversa está;
- **VS Code:** vem para a frente a janela do projeto da conversa. As abas de
  terminal do VS Code mostram o nome do programa, e o aviso indica o ajuste
  que faz elas mostrarem o assunto da conversa;
- **Prompt de Comando ou PowerShell em janela própria:** a própria janela vem
  para a frente.

## Quando não dá para saber a janela

No VS Code, todas as janelas pertencem ao mesmo programa, e a janela da
conversa é reconhecida pelo projeto aberto nela. Se a conversa roda numa
pasta que não é o projeto de nenhuma janela aberta, o TrackerTalk não escolhe
uma ao acaso: o aviso lista as janelas em que ela pode estar.

Com mais de uma janela do Windows Terminal, vale a que mostra a aba da
conversa. Se ela não for a aba ativa de nenhuma janela, o aviso diz em quantas
janelas procurar.

A aba exata, dentro do VS Code ou do Windows Terminal, não é selecionada: de
fora desses programas não há como fazer isso.

## Sem mexer no terminal

O TrackerTalk só lê o título do terminal e dá foco à janela. Nada é escrito no
terminal da conversa.

Se o Windows recusar trazer a janela para a frente, ela pisca na barra de
tarefas, e o aviso diz isso.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao das versões anteriores;
- dados, rastreios, projetos e imagens existentes são preservados;
- verificada a atualização a partir da 0.10.2 com o programa aberto.

## Atualizando

Execute o instalador por cima da instalação atual. Conversas em
andamento podem continuar abertas.

## Observação do Windows

O instalador ainda não possui assinatura Authenticode. O Windows Defender
SmartScreen pode apresentar um aviso antes da execução. A página de
distribuição explica o que fazer e como verificar o arquivo.
