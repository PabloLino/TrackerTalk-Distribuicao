# TrackerTalk 0.7.0

Primeira versão proprietária gratuita do TrackerTalk e primeira versão com
atualizador integrado.

## Atualizações

- verificação automática no máximo uma vez a cada 24 horas;
- verificação manual pelo menu da bandeja e pelo comando `trackertalk update`;
- aviso automático exibido no máximo uma vez para cada versão;
- download somente da Release oficial por HTTPS;
- validação do nome da versão, endereço, tamanho e SHA-256;
- confirmação separada para baixar e para executar o instalador;
- falhas de rede não interferem no rastreamento local;
- nenhuma atualização é obrigatória;
- atualização fecha somente o agente TrackerTalk, nunca CLIs de IA.

## Comandos

```powershell
trackertalk update check
trackertalk update check --json
trackertalk update download
trackertalk update install
```

## Licenciamento

A versão 0.7.0 é distribuída sob a Licença de Uso Gratuito do TrackerTalk 1.0.
Pessoas e organizações podem instalar e usar o aplicativo sem cobrança,
inclusive profissionalmente. O código-fonte autoral permanece privado.

A versão 0.6.4 continua sob MIT. A mudança não remove os direitos concedidos
anteriormente àquela versão.

O instalador inclui a licença do TrackerTalk, o aviso de componentes de
terceiros e os textos integrais disponíveis das dependências empacotadas.

## Compatibilidade e dados

- Windows 10 ou 11 x64;
- instalação por usuário, sem privilégios administrativos;
- esquema de dados local: 1, igual ao da versão 0.6.4;
- dados e rastreios existentes são preservados;
- a opção anterior de iniciar com o Windows é respeitada;
- desinstalar preserva os dados locais por padrão.
